## 3. P0 — Critical After Effects indexed-property reference invalidation

**Files:**

- `src/core/Engine.js`
- `src/adapters/TargetResolver.js`
- `src/controllers/ControllerManager.js`
- `src/adapters/AEDom.js`

### Root cause

The current execution order is:

1. Resolve selected Starglow Threshold.
2. Store direct Property reference in `targetItem.prop`.
3. Begin applying recipe.
4. Create multiple Expression Controls on the target layer.
5. Reuse the previously stored Property reference.
6. Assign expression.

This is unsafe in real After Effects.

Adobe's PropertyGroup API documents that adding a property to an indexed group recreates the group and invalidates references to existing children.

Starglow resides under the indexed Effects group.

Adding Slider Controls to that same group can therefore invalidate the previously captured Starglow Threshold reference.

The issue is not captured by current Node mocks because they retain object references across simulated addProperty calls.

### Independent reproduction

A mock was configured to invalidate indexed Effect references after addProperty.

Result:

- `Apply` returned failure.
- Threshold expression remained empty.
- Six controller effects remained after unsuccessful rollback.
- One attempted rollback could not remove invalidated references.

This is a reproduction of a documented AE API behavior in a mock, not a confirmed AE host execution.

### Mandatory fix

Implement a Property Reference Survival Strategy.

Before any structural mutation:

- Capture owner layer identity.
- Capture the indexed Effect instance index.
- Capture its matchName.
- Capture the complete propertyIndex chain.
- Capture the selected child property identity.
- Capture original expression and property state.

After addProperty or removeProperty:

- Reacquire the indexed Effects group.
- Reacquire the correct effect instance by verified index/identity.
- Reacquire the target property.
- Verify matchName and identity.
- Only then assign or modify its expression.

Never rely on a cached Property object surviving indexed-group mutation.

Avoid accidental targeting of a different effect instance when indices shift.

Prefer stable identities where supported, but never assume an index remains stable after deletion or reordering.

### Acceptance

A Starglow Threshold reference remains correctly resolvable after seven or more Expression Controls are created on the same layer.

No Object Is Invalid errors.

No unintended effect changes.

No leaked controllers after failed transactions.
